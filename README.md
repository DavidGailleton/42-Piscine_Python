# 42 Piscine Python

My exercises for the Python modules at 42 Lyon: eleven modules (`00` to `10`), each a folder of small exercises.

| Module | Topic |
|---|---|
| `00` | First functions, input, loops, recursion |
| `01` | Classes, inheritance, encapsulation |
| `02` | Exceptions: `try` / `except` / `finally`, raising, custom errors |
| `03` | Collections and `sys.argv`: lists, tuples, sets, dicts, generators |
| `04` | Reading and writing files, `with`, standard streams |
| `05` | Abstract classes and polymorphism (`abc`), a small data pipeline |
| `06` | Modules, packages, imports, circular imports |
| `07` | Abstract classes and multiple inheritance (a card game) |
| `08` | Virtual environments, dependencies (pandas, numpy, matplotlib), environment variables |
| `09` | Data validation with pydantic |
| `10` | Functional tools: lambdas, closures, decorators, `functools` |

The code is typed and checked with flake8 and mypy, as the 42 subjects ask.
